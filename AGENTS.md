# AGENTS.md: my-school-BE

A school management REST API built with NestJS 11, TypeScript, Prisma 7 and PostgreSQL 16, using JWT auth. All routes are under `/api/v1`.
Codex reads this file, and so does Claude Code (through `CLAUDE.md`). Keep it short: it's loaded into every session.

## Commands

| Task                  | Command                                                                                                                                                                                                                                     |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Install               | `pnpm install --frozen-lockfile`                                                                                                                                                                                                            |
| Dev server            | `pnpm db:start && pnpm start:dev` (Swagger at `/api/docs`)                                                                                                                                                                                  |
| Lint / format / build | `pnpm lint` · `pnpm format:check` · `pnpm build`                                                                                                                                                                                            |
| Tests                 | `pnpm test` · `pnpm test:e2e` · `pnpm test:cov`                                                                                                                                                                                             |
| Prisma                | `pnpm prisma:generate` · `pnpm prisma:migrate:dev --name <x>` (local only). `prisma.config.ts` needs `DATABASE_URL` set, even a dummy value                                                                                                 |
| Agents                | `pnpm agents:build` (regenerate from code) · `pnpm agents:check` (fails when generated files are stale; stale notes only warn unless `staleNotes: "fail"`) · `pnpm agents:stamp <module>` (mark notes as verified against the current code) |

## Repo map

- `src/modules/<name>/`: feature modules (module, controller, service, types, dto, index).
- `src/common/`: guards (global JWT → Roles → Throttler; there are no permission flags), decorators (`@Public`, `@Roles`, `@CurrentUser`), filters, interceptors, utils (`getTodayInSchoolTimezone`), and constants (`ERROR_*`).
- `src/modules/request-access/`: `AccessPolicyService`, which decides per-record teacher access (class or subject teacher, or an admin-approved `AccessRequest` grant). It's used by attendance, dashboard, exams, grades and homework.
- `src/config/`: env validation (zod) and config factories.
- `prisma/schema/*.prisma`: the schema split by domain, plus `migrations/`.
- **Source of truth is the code.** `docs/`, `ATXDocumentation/`, `deployment/` and `README.md` may be outdated. Agents learn behaviour only from `src/`, `prisma/` and the generated `.agents/catalog/`.

## Rules for every agent

1. The standards are binding:
    - `.agents/standards/coding-standards.md`
    - `.agents/standards/testing-standards.md`
    - `.agents/standards/release-standards.md`
2. Before touching a module, read its owner agent (`svc-<module>`). Before changing its contract (exports, routes, DTOs, shared models), run the `impact-analysis` skill.
3. Never run `prisma migrate reset`, `db push` or seed scripts against a non-local database. Never commit secrets. Never deploy.
4. After any code change, run `pnpm agents:build`. If a module's behaviour changed, re-verify `.agents/services/<module>.notes.md` **against the code**, then run `pnpm agents:stamp <module>`.
5. Finish with verification: `pnpm lint && pnpm build && pnpm test` (see testing-standards §0 for known test-infrastructure breakage).

## Agent system

- The source files live in `.agents/`: `specs/`, `services/*.notes.md`, `templates/`, `skills/`, `standards/` and `agents.config.json`.
- `scripts/agents/build.mjs` generates the Claude subagents (`.claude/agents/*.md`), the Codex agents (`.codex/agents/*.toml`), `.claude/skills/`, `.agents/catalog/` and the roster below. **Never edit generated files.**
- To orchestrate a feature end to end, follow the `feature-pipeline` skill:
    1. `svc-*` agents give context.
    2. `service-creator` builds.
    3. `code-reviewer`, `security-auditor`, `migration-guardian` and `api-contract-guardian` check.
    4. `tester` tests.
    5. `release-checker` gives a verdict.
- Subagents can't spawn subagents, so the main thread dispatches each step.
