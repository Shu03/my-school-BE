Test Checklist — Exam Service (multi-subject model)

NOTE: One Exam is an event (e.g. "Mid Term March 2026") that contains MANY subjects.
Each subject entry (ExamSubject) has its OWN totalMarks and date. Grades are recorded
per exam-subject. Finalizing locks the WHOLE exam (all subjects).

Create request body shape:
  POST /exams
  {
    "name": "Mid Term",
    "type": "MID_TERM",
    "classId": "<class-uuid>",
    "academicYearId": "<year-uuid>",   // optional → defaults to current year
    "termId": "<term-uuid>",           // optional
    "subjects": [
      { "subjectId": "<subj-uuid>", "totalMarks": 100, "date": "2026-03-10" },
      { "subjectId": "<subj-uuid>", "totalMarks": 50,  "date": "2026-03-12" }
    ]
  }

Create Tests
Test 1  — POST /exams (Admin) → create MID_TERM for Class 6A with 2 subjects → 201, returns subjectSummaries
Test 2  — POST /exams (class-teacher Teacher) → create with 1+ subjects → 201
Test 3  — POST /exams → no academicYearId → defaults to current year ✓
Test 4  — POST /exams with empty subjects array → 400 (ArrayNotEmpty)
Test 5  — POST /exams with duplicate subjectId in subjects[] → 400 duplicate subject
Test 6  — POST /exams where a subject's gradeLevel != class gradeLevel → 400
Test 7  — POST /exams with termId not in the year → 400
Test 8  — POST /exams (Teacher not class-teacher of class) → 403
List + Get Tests
Test 9  — GET /exams (Admin) → sees all active exams, each with examSubjects
Test 10 — GET /exams?type=MID_TERM → filters by type
Test 11 — GET /exams?status=ACTIVE → filters by status
Test 12 — GET /exams?subjectId=<id> → returns exams that include that subject
Test 13 — GET /exams/:id → returns exam with per-subject subjectSummaries (gradeCount, averageMarks)
Test 14 — GET /exams (Student) → only exams for enrolled classes
Test 15 — GET /exams (Teacher with GRADES_READ) → only assigned class exams
Update Exam Tests (name / type / termId only — no marks/date at exam level)
Test 16 — PATCH /exams/:id (Admin) → update name, type, termId → 200
Test 17 — PATCH /exams/:id (creator Teacher) → 200
Test 18 — PATCH /exams/:id (non-creator Teacher) → 403
Test 19 — PATCH /exams/:id with no fields → 400 "At least one field must be provided: name, type, termId"
Test 20 — PATCH /exams/:id update termId to term from different year → 400
Test 21 — PATCH /exams/:id (finalized exam) → 400 cannot update finalized
Manage Subjects Tests
Test 22 — POST /exams/:id/subjects (Admin/creator) → add a subject { subjectId, totalMarks, date } → 201
Test 23 — POST /exams/:id/subjects duplicate subject already on exam → 400
Test 24 — POST /exams/:id/subjects with gradeLevel mismatch → 400
Test 25 — POST /exams/:id/subjects on finalized/discarded exam → 400
Test 26 — POST /exams/:id/subjects (non-creator Teacher) → 403
Test 27 — PATCH /exams/:id/subjects/:subjectId → update totalMarks and/or date → 200
Test 28 — PATCH /exams/:id/subjects/:subjectId with no fields → 400 "At least one field must be provided: totalMarks, date"
Test 29 — PATCH /exams/:id/subjects/:subjectId on finalized exam → 400
Test 30 — DELETE /exams/:id/subjects/:subjectId → 200 removes subject (grades cascade)
Test 31 — DELETE /exams/:id/subjects/:subjectId when it is the LAST subject → 400 (exam must keep ≥1 subject)
Test 32 — DELETE /exams/:id/subjects/:subjectId subject not part of exam → 404
Finalize Tests (locks the whole exam — all subjects)
Test 33 — POST /exams/:id/finalize (Admin) → 200 isFinalized: true
Test 34 — POST /exams/:id/finalize (creator Teacher) → 200
Test 35 — POST /exams/:id/finalize (non-creator Teacher) → 403
Test 36 — POST /exams/:id/finalize (already finalized) → 400
Unlock Tests
Test 37 — POST /exams/:id/unlock (Admin) → 200 isFinalized: false
Test 38 — POST /exams/:id/unlock (Teacher) → 403
Test 39 — PATCH /exams/:id (after unlock) → 200 can update again
Discard Tests

Test 41 — POST /exams/:id/discard (Teacher) → 403
Test 42 — GET /exams → discarded exam not in results
Test 43 — GET /exams?status=DISCARDED → shows discarded exams
Test 44 — POST /exams/:id/finalize (discarded exam) → 400
